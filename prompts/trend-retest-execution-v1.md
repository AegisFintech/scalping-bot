# Registered structural trend demo execution

The immutable context binds the CODEX proposal, frozen trend profile, source hash
and exact completed-candle input. Execution verifies the original range, trend,
confirmation and nearest known structural target. Retest LIMIT retains the trend
direction; STOP_LIMIT follows the breakout. WAIT never falls back to local entry.
Fresh session, quote, account, reconciliation, trial, cost, dynamic sizing and margin
checks remain mandatory. Pending orders retain their exact absolute SL/TP, recorded
60-second capture-based expiry and order type. Profile changes require exact terminal
proof and fresh reconciliation; this artifact grants no broker authority.
