## Three research definitions

All hypotheses use the latest five completed M1 bars available to the original
provider input, M5 direction from the last three completed closes, and a one-tick
buffer outside that range. This fixed research direction is not an extra production
gate; M15/SMC/DOM remain actual provider context. For five whole M1 bars beginning
after actual validated model availability, compare:

- RANGE_BREAK: completed-bar high/low first reaches the buffered boundary.
- BAR_CONFIRM: a completed close first finishes beyond that boundary.
- BREAK_RETEST: a prior completed close broke out; a later bar touches the boundary
  and closes beyond it. No same-bar break/retest ordering is invented.

The opposite range edge plus one tick is a structural stop reference. The target
reference adds structural stop distance plus twice the originally recorded minimum-
volume cost/exit-reserve context; reference distances above7price units are unavailable.
This is a cost-room diagnostic, not actual-volume sizing or a replacement risk rule.
Actual current policy retains its independent volume/FX/commission/precision checks.
Reject unordered input carriers and retain their coverage counts. First retained
later input-request clocks bound when completed path bars were
observed. Only receipts before the collection cutoff participate. Missing/marked-gap/
conflicting paths are censored or unavailable; a full path with no event is negative.
Event-bar target/stop touches or both levels in one bar remain ambiguous. Later bar
level order and excursions describe prices, never executable fills, saved trades,
realized expectancy or profits. Counterfactual fill/net remains null. Include every
origin/candidate and window-edge censoring; do not select complete winners.

The new observer pins the complete Python source closure, requirements and policy,
release, definitions and all three candidates before a future half-hour boundary.
It retains one original input/report per window, processes one missing window/tick,
locks against overlap and rejects source/release drift. Five-minute settling,
7-day maximum,256MiB/5,000-file cap,2GiB free reserve and unprivileged SELECT-only
service apply. Registration is root-owned0444; reports are retained separately from
7-day logs. This collection batch is not independent economic qualification. Overlapping
context windows are not independent trials; event counts are not trade counts.
