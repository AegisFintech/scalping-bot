## Delivered boundary

One existing demo executor supplies a SELECT-only half-hour evidence packet.
The restricted SSH account can only read that sanitized file. On tc01 the existing
non-login `scalper-learning` identity imports it into its existing immutable archive,
registers a descriptive diagnostic, executes the current-contract replay, durably
claims one Codex interpretation, validates its exact result digest, records a finding
and closes that review plan. The finding proposes one next question and falsification
test. It is not evidence that the proposed experiment was run or that a strategy works.

The scope is an additive `current-observation-agenda` beneath the existing source
archive. The earlier source inspection proposed extending the old Aurum advisor and
its training-plan store. Implementation instead reuses the primary bot's already
restricted Codex transport and archive. This avoids importing the root launcher,
paper promotion, frozen training-dataset assumptions, float economics and publishing
tools. It preserves the useful durable claim/result/finding/closure semantics; old
Aurum plans, thirteen unknown jobs, frozen trials and historical findings are untouched.
It is a replacement current-observation review scope, not a claim that old agenda jobs
have closed or that the old autonomous supervisor has been repaired/reactivated.

The model has no tool catalogue. Shell, code mode, plugins, apps, MCP servers and
network-search tools are disabled; unexpected tool/server requests abort the transport.
The existing entry worker retains its default instructions and separate home/thread.
Research has its own prompt pin, dedicated home, daily resumed thread and existing
compaction behavior. Memory provides context, not training or current evidence.
The shared transport gains only a trusted `purpose` argument for its base instructions.

## Evidence and failures

Original packet bytes, immutable archive manifests, source-pinned diagnostic registration,
full result, request/claim, raw response, attributed finding and closure remain local.
The model receives all cohort/reason counts, role denominators, recorded closed-row
statistics and limitations; detailed per-setup reconstruction is retained locally.
Unknown counterfactual costs remain null, actual money remains decimal strings, and
carry-ins are never summed across windows into an apparent trade total. Without quote
paths, sampled profit giveback and hypothetical exit proceeds remain unavailable.

Window identity prevents a repeated export from buying another call. A separate
half-hour claim limits different cohorts to at most one new provider request per slot.
Unknown/invalid responses retain their claim; they never replay. A later fresh window
may make a separate request. Finding-before-closure interruption finishes idempotently.
Tampered input/results, bad provenance, stale intake, source mismatch and oversized
input fail closed. An old completed packet reports STALE_FEED, not current health.
A failed intake leaves historical completion in the archive; health never assumes zero.
Registration is descriptive and precedes computation; this is not a prospective study.
